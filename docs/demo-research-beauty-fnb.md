# 뷰티·F&B 데모 상담 경험 개선

2026-09-23 기준. 대상 9개 서비스, 신규 상담 문항 20개. 기존 촬영·색상·맛·무드 입력에 서비스별 맥락을 더하며, 임의로 대기 시간을 늘리는 대신 사용자가 의미 있는 선택을 하는 시간을 확보했다. 표기 시간은 사용자 선택 속도에 따른 추정치이며 사진 생성 시간은 별도로 안내한다.

## 조사와 설계 근거

- [American Academy of Dermatology — 건조 피부 관리](https://www.aad.org/public/everyday-care/skin-care-basics/dry/dermatologists-tips-relieve-dry-skin): 순한 세안, 세안 후 보습, 무향 제품 선택을 기본 루틴에 반영했다. 피부의 실제 느낌을 물어보는 이유는 사진의 밝기나 대비가 건조감 자체를 알려주지 않기 때문이다.
- [AAD — 제품 사용 전 작은 부위 테스트](https://www.aad.org/public/everyday-care/skin-care-secrets/prevent-skin-problems/test-skin-care-products): 새 제품의 자극 경험을 질문하고 7–10일 작은 부위 테스트 안내를 추가했다. 이 체험은 알레르기 검사나 진단을 하지 않는다.
- [AAD — 자외선 차단제 선택](https://www.aad.org/public/everyday-care/sun-protection/shade-clothing-sunscreen/choosing-right-sunscreen): 광범위 SPF 30 이상 차단을 아침 기본 단계에 포함했다. 모델이 생성한 루틴을 쓰더라도 기본 차단 단계를 유지한다.
- [World Coffee Research — Sensory Lexicon](https://worldcoffeeresearch.org/read-more/news/174-world-coffee-research-sensory-lexicon): 커피 향·맛·질감을 분리해서 묻는 구조를 참고했다. 사용자가 보고한 기호도와 훈련된 평가자의 강도 측정은 구별한다. 본 데모의 향 노트는 관능 표현이며 실제 원두의 측정 성적서가 아니다.
- [WSET — 와인 테이스팅 학습](https://www.wsetglobal.com/knowledge-centre/blog/2019/november/how-to-build-your-wine-tasting-skills): 산미·단맛·탄닌·바디를 구분한다는 원칙을 반영해 기존 쌉쌀함과 별개로 입안이 마르는 탄닌 느낌을 물었다.
- [WSET — 음식과 와인 페어링](https://www.wsetglobal.com/knowledge-centre/blog/2023/july/13/four-rules-to-masterful-food-and-wine-pairing): 음식의 단맛·산미·지방·매운맛에 따라 한 잔의 인상이 변하므로 주재료 외에 소스의 맛을 수집한다.

위 자료는 설문 방향과 일반적인 관리 원칙의 근거다. 각 서비스의 컬러 팔레트·네일 패턴·브루 레시피·칵테일 조합은 이 사이트의 체험용 설계이며 전문 기관이 검증하거나 승인한 알고리즘이라고 주장하지 않는다. 향수는 화면으로 향을 전달하지 못하므로 현장 시향용 후보와 사용 장면을 정리하는 목적이다.

## 사실성 개선

- 피부 사진의 밝기·대비에 난수를 더해 만들던 수분·탄력·모공 점수 및 동연령 순위를 제거했다. 얼굴 위 임의 색상 맵도 제거하고 상담 사진을 그대로 표시한다.
- 피부 결과를 자기보고 기반 루틴으로 바꿨다. 서버 모델 역시 수분·탄력·질환을 추정하지 않도록 수정했다. 기존 응답의 `scores` 필드는 호환성 때문에 고정값 50을 유지하지만 화면·인쇄·해석에는 전혀 쓰지 않는다.
- 메이크업의 468개 랜드마크, 가짜 fps, 피부 호수·온도 측정과 해시 기반 궁합 점수·순위를 제거했다. 선택한 팔레트의 색 방향과 실제로 고른 표현 강도를 보여주는 컬러 스타일 가이드로 교체했다.
- 네일의 사진 시드로 만든 mm 치수, 곡률, 실제 젤 스티커처럼 보이던 제작 안내를 제거했다. 렌더링용 폭은 일러스트 비율이며 실제 제작 전 별도 실측이 필요하다.
- 미각 DNA의 임의 인구 상위 희귀도와 염기서열 분석 문구를 제거했다. 나선과 DNA 명칭은 취향을 표현하는 장치이며 유전자 분석이 아니다.
- 소믈리에의 2,400종·바리스타의 100여 종·향수의 200종 데이터베이스 비교 주장을 제거했다. 남아 있는 매칭값은 데모 취향 비교 지표로 표현하며 측정 정확도나 확률이 아니다.
- 퍼스널 컬러 서버 프롬프트는 사진·드레이핑 없는 설문을 검증된 진단처럼 말하지 않으며, 반대 팔레트를 금지색 대신 비교할 색으로 설명한다.

## 검증

- 담당 9개 데모 + 경험 설정 + 피부/퍼스널컬러 서버 스펙: ESLint 통과.
- 최종 `npx tsc --noEmit --pretty false` 통과.
- 설정 9개·문항 20개, 서비스별 준비 항목 2개·처리 단계 3개·선택지 3–5개 및 결과 조언 누락 여부 실행 검증 통과.
- TypeScript AST로 실제 순수 함수를 불러오는 실행 검증: 도구 선택에 따른 커피 추출 강제 적용, 아이스 드립 물·얼음 총량, 자극 경험 우선 피부 분기, 매트·시어 프리뷰, 식물성 음식·음료·미션 교체 16개 assertion 통과.
- 유료 모델 호출 및 실제 카메라·프린터·시향·시음은 이 분담 작업에서 수행하지 않았다. 전체 브라우저/서버 연동 검증 결과는 통합 보고서에서 확인한다.
