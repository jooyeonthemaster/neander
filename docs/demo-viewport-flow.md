# 데모 화면 분리와 반응형 무대

2026-09-23 추가 요청 반영. 이전 이미지·서체·서비스별 색상은 유지하고, 41개 데모의 정보 밀도와 진행 방식을 수정했다.

## 화면 구성

1. **소개**: 서비스 사진과 핵심 제목, 짧은 초대 문장만 표시한다.
2. **체험 설정**: 한 단계에 질문 하나를 표시한다. 선택지의 긴 설명을 모두 나열하지 않고 현재 선택의 설명만 보여준다.
3. **촬영·선택·입력**: 현재 할 일에 집중한다. 이름·직함 같은 텍스트 입력과 취향 슬라이더는 항목마다 페이지를 나눈다.
4. **결과**: 결과 카드별로 넘겨 읽는다. 맞춤 가이드와 출력물 저장은 별도 탭에서 확인한다.

상단의 중복 분류 배지·부제와 작업 화면의 반복 안내를 줄였다. ‘서비스 자세히 보기’와 단계 이동 버튼은 화면 안에 계속 보인다. 결과의 샘플 표시, 필요한 범위 안내, 실제 다운로드 내용은 보존했다.

## 화면 크기 대응

팝업은 둥근 외곽 안쪽에 콘텐츠 영역을 배치한다. 데모 자체는 팝업·상세 페이지·전체 화면에서 가용 높이를 사용하고 스크롤하지 않는다. 긴 내용은 ‘이전 내용 / 다음 내용’으로 이동한다. 페이지 경계는 입력 항목과 결과 카드 등 의미 단위를 우선하고, 작은 화면에서는 버튼과 문장 경계를 측정해 추가 분할한다.

페이지를 바꿀 때 카메라, 오디오, 실험, 결과 컴포넌트는 유지된다. 현재 화면 밖의 조작은 키보드 포커스에서도 제외한다. 카메라·출력물·포토카드·뮤직비디오의 미리보기는 가용 높이에 맞추며, 저장 이미지의 해상도는 유지한다.

작은 가로 화면에서는 상단 진행 장식과 반복 부제를 생략해 조작 공간을 확보한다. 콘텐츠를 한꺼번에 축소해 읽기 어려워지게 하지 않고 추가 페이지로 나눈다.

## 서비스별 보정

- 제품 상담: 현재 질문과 응답만 표시하고 이전 대화는 기록 보기에서 한 문답씩 확인한다. 자유 입력과 선택 답변을 같은 자리에서 전환한다.
- 커플 체험: 두 사람의 사랑 표현 질문을 A·B 각각의 단계로 나눠 한 번에 한 사람의 답을 받는다.
- 과학 실험: 미션 → 도식과 조작부 → 관찰·해설로 나눈다. 비교 실험의 첫 조건과 두 번째 조건을 보존한다.
- 카메라: 촬영 영역의 안내를 짧게 줄이고 긴 권한 오류 설명은 별도 내용으로 둔다.
- 패션 타임머신: 시대 카드에는 연도·스타일명·컬러만 남기고, 상세 설명은 현재 누른 시대 하나만 표시한다. 320×740·320×568·844×390에서 6개 버튼의 잘림 없는 접근과 최대 3개 선택을 확인했다.
- 팬 포토카드·뮤직비디오: 작품과 조작이 잘리지 않도록 미리보기 크기만 조정한다.

## 검증

- 41개 데모 × 데스크톱 1440×900·모바일 320×740, 총 82개 전체 흐름(소개 → 체험 질문 → 기존 입력 → 결과 → 맞춤 가이드 → 다시 시작)을 확인했다. 추가 질문 값의 API 전달과 재시작 초기화를 포함한다.
- 전체 41개 × 두 해상도, 82개 소개 화면에서 사진·큰 글씨와 고정 이동 버튼, 화면 넘침을 확인했다.
- 대표 서비스의 320×568 ↔ 844×390 회전, 팝업·상세 페이지·전체 화면에서 넘침과 기본 조작을 확인했다.
- 제품 상담은 3개 해상도에서 네 답변, 대화 기록 왕복, 직접 입력, API 요청 보존을 확인했다.
- 과학은 320×740에서 고등 난이도 4종의 비교 실험을 확인했다. 같은 조건을 반복했을 때와 바꿨을 때의 진행 조건이 구분된다.
- 소믈리에의 슬라이더 4개, 명함의 입력 4개가 항목별 페이지에 표시되고 키보드 입력을 유지한다.
- 결과·가이드·출력 탭 왕복, 마지막 페이지에서 창 크기 변경, 페이지 방향키, 팝업 Tab 순환을 확인했다. 숨겨진 페이지로 포커스가 이동하지 않는다.
- 출력 탭을 처음 방문할 때 인쇄가 시작되고, 탭 왕복 후 출력 상태를 유지하며 1200×1800 JPEG 다운로드가 정상이다.
- TypeScript와 데모 ESLint, 프로덕션 빌드가 통과했다. 빌드는 214개 페이지를 생성했다.

검증 기록은 로컬 `.playwright-mcp/viewport/`, `.playwright-mcp/demo-viewport/`, `.playwright-mcp/viewport-simple/`, `.playwright-mcp/viewport-product-compact/`에 보관한다.

브라우저 흐름 검증에서는 AI API에 의도적인 503 응답을 주고 샘플 결과 경로와 입력 보존을 확인한다. 실제 AI 생성 품질을 검증한 것으로 해석하지 않는다.
