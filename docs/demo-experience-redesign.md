# 서비스 데모 체험 개편 보고서

작성일: 2026-09-23 · 대상: 서비스 페이지에서 제공하는 41개 데모 전체

후속 시각 개편: [41개 서비스 아트디렉션 보고서](demo-art-direction.md). 현재 화면은 서비스별 배경·13개 한글 서체 계열·10가지 구성과 확대된 글자를 사용한다. 아래는 질문과 체험 동작의 개편 기록이다.

## 반영한 경험

41개 데모에 각 서비스의 목적에 맞는 공간 이름, 사진, 배색, 첫 안내, 추가 상담, 작업 안내와 가져갈 결과물을 구성했다. 공통 내비게이션과 글자·간격 체계를 유지하면서 스튜디오·카운터·아틀리에·전망실·갤러리·라운지·실험실의 7가지 화면 구성을 사용한다. 기존 실제 행사 사진 4종과 새 콘셉트 이미지 37종을 체험 화면에도 연결했고, 사진의 출처 성격을 표시한다.

추가 질문은 총 86개, 선택지는 266개다. 카드·스와치·단계 선택·칩으로 답하고, 질문마다 어떤 결과에 쓰이는지 먼저 설명한다. 전체 설정을 마친 뒤 기존 촬영·녹음·선택·직접 실험 단계에 들어간다. 준비한 조건은 진행 중 안내, 결과의 맞춤 가이드, AI 텍스트·이미지 생성 요청, 저장용 출력물에 이어진다.

- 메이크업: 조명과 피부 표현을 먼저 선택하고, 시어·새틴·벨벳 표현을 실제 미리보기와 출력에 적용한다.
- 피부: 오후의 피부 상태·자극 경험·관리 시간을 바탕으로 AM/PM 루틴을 안내한다. 사진에서 수분·탄력·질환을 측정하는 것처럼 표현하지 않는다.
- 커피·주류·미각: 추출 도구, 온도, 탄닌, 소스 맛, 탄산 질감, 식사 제약 등 실제 선택에 필요한 조건을 반영한다.
- 패션·웨딩: 날씨·보행, 촬영 조명, 포즈의 편안함, 인화 용도와 원하는 표현을 받는다.
- 음성·영상: 음성 녹음은 10초로 늘리고, MV 편집은 선택에 따라 15/20/24초로 바뀐다. 추억 영화의 시간순 모드는 사용자가 정렬한 사진 순서를 유지한다.
- 과학: 두 조건 비교를 고르면 실제로 값을 바꾸어 두 번 실행해야 진행된다. 첫 조건과 마지막 관찰을 결과와 실험 노트에 남긴다.
- 진로·팀·커플: 활동·상황·사용 가능한 시간을 받고 실행할 작은 과제나 대화 활동을 제안한다. 짧은 체험을 검증된 심리·적성 검사처럼 제시하지 않는다.

체험 시간은 서비스별 약 2–4분을 안내하며, 이미지 생성 대기 시간은 별도다. 추가 정보와 직접 조작에 시간을 쓰도록 했으며, 단지 길게 보이기 위한 대기 시간은 더하지 않았다. 처리 화면에는 경과 시간을 표시하고 입력으로 돌아갈 수 있다.

## 조사 근거와 적용 범위

외부 자료는 질문의 방향과 일반적인 안내 원칙에 사용했다. 이 체험 설문 자체가 해당 기관의 인증을 받은 검사나 전문 평가 도구라는 의미는 아니다.

- 피부 관리와 자극 경험은 AAD, 맛의 구분과 페어링은 World Coffee Research·WSET 자료를 참고했다. 서비스별 질문과 실제 결과 변화는 [뷰티·F&B 조사 기록](./demo-research-beauty-fnb.md)에 정리했다.
- 음성 환경은 NIDCD, 문화재의 실제 보존과 창작 장면 구분은 UNESCO, 이동 환경 선택은 한국관광공사 자료를 참고했다. [포토·문화·여행 조사 기록](./demo-research-photo-culture.md)에 출처와 한계가 있다.
- 활동 중심 진로 탐색은 O*NET, 변수 비교 실험은 NASA JPL, 팀 대화는 심리적 안전과 규범 명확성에 관한 1차 연구를 참고했다. [교육·행사·기업 조사 기록](./demo-research-learning-events.md)에 상세 문항과 출처가 있다.
- 모달 포커스는 [WAI-ARIA Dialog Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/), 터치 영역은 [WCAG Target Size](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)를 참고했다. 새 주요 선택 버튼은 최소 44px 높이로 구성했다.

## 결과의 신뢰 범위

실측 근거가 없는 피부·신체·능력 수치, 확인되지 않은 데이터베이스 비교 건수, 미래 성공·유전·성격 예측 표현을 정리했다. 운세·오라·상상 가족·역사 합성 등 창작 체험에는 그 성격을 해당 화면에서 설명한다. 기존 스키마 호환 때문에 유지되는 일부 숫자 필드는 화면에 측정값으로 표시하지 않는다.

AI 응답이 없거나 사진을 인식하지 못하면 준비된 예시와 선택 기반 가이드로 이어지며, 화면과 출력물에 체험 예시임을 표시한다. 외부 AI 이미지의 발색·착장·역사 고증·현재 가격과 재고 등을 보증하지 않는다. 실제 현장 장비·실물 시향·시음·프린터와는 차이가 있다.

## 검증 결과

- 프로덕션 빌드: `npm run build` 성공. TypeScript 검사와 140개 정적 페이지 생성 완료.
- 수정 범위 ESLint: 공통 데모 UI·41개 모듈·설계 데이터·AI 서버 경로 모두 오류/경고 없이 통과.
- 브라우저 전체 흐름: 41개 모두 추가 설정 → 기존 질문/샘플 촬영·음성·직접 실험 → 결과 가이드 → 다시 시작 통과. 각 API 요청의 profile 전달과 모든 추가 문항의 결과 표시를 확인했다. 외부 모델 대신 503 응답을 의도적으로 넣어 실패 시 체험이 이어지는 경로를 검증했다. 브라우저 오류 0건.
- 모바일: 8개 대표 서비스 × 390/320px = 16개 조합에서 실제 7종 화면 구성 확인. 이미지 로드, 가로 넘침, 44px 주요/보조 터치 영역, 선택 후 진행 모두 통과.
- 320px 결과: 프린터 미리보기의 고정 폭 때문에 잘리던 문제를 수정했다. 메이크업 JPEG 다운로드 1200×1800 확인; 미리보기만 화면에 맞게 축소되고 저장 해상도는 유지된다.
- 키보드: 모달 안 Tab/Shift+Tab 순환, Esc 닫기, 원래 서비스 카드로 포커스 복원, 배경 스크롤 복원 통과.
- 요청 수명주기: 6.5초 지연 응답으로 분석 취소/답변 변경/재요청 및 닫고 재열기를 검증했다. 이전 응답이 새 체험 화면을 덮어쓰지 않고, 취소 시 답변 보존·재입장 시 초기화가 정상 동작한다.
- 서버 컨텍스트: 41개 설계·86문항·266선택지 대응, 잘못된 ID/임의 지시문 제거, 50명의 동시 JSON·이미지 요청 100건의 입력 격리, 중첩/예외 이후 컨텍스트 복원을 실제 함수 실행으로 확인했다.
- 실제 외부 AI 요청: 퍼스널 컬러 1건 HTTP 200, 약 6.4초. 추가 선택 ‘특별한 날·선명한 대비’가 설명과 조합 팁에 반영됐다. 그 실제 응답의 브라우저 결과 표시와 영수증 저장도 확인했다.
- 개별 동작: 피부 루틴 분기, 네일 마감, 커피 도구·아이스 물량, 식물성 미각 가이드, MV 15/20/24초, 사진 순서/엔딩 보존 등 실행 검증을 각 조사 기록에 남겼다.
