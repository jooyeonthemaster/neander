# 뷰티·F&B 프로그램별 아트 디렉션

2026-09-23. 같은 어두운 대시보드의 색상만 바꾸는 방식에서 벗어나, 프로그램마다 서로 다른 인쇄물·공간·도구를 출발점으로 구성했다. **9개 프로그램에 9개 composition, 9개 제목/본문 서체 조합, 밝은 테마 6개·어두운 테마 3개**를 배정했다. 공통 배경 격자나 네트워크 선은 추가하지 않는다.

## 구현

- `src/data/demo-experiences/art-beauty-fnb.ts`: 개별 프로그램 이름, 컨셉, 서체, 종이·잉크·강조색, 사진 크롭과 배경 배치, 화면 구성.
- `src/components/demo/program-beauty-fnb.css`: 모든 규칙을 `.experience-venue[data-program='서비스 slug']`에 한정. 서비스별 프레임·옵션·질감·실루엣·가이드·버튼을 조정한다.
- 타이포그래피의 기본 크기는 공통 렌더러가 확대하며, 이 CSS에는 `font-size` 축소 규칙이 없다. 사진은 기존 서비스별 이미지 자산을 사용하고 새 생성 이미지는 추가하지 않았다.
- 기존 설문, AI 요청과 결과 계산 로직은 유지한다. 통합 대비 점검에서 짙은 결과 카드와 강조 버튼·번호 배지에 명시적인 색상 클래스만 추가했다.

## 직접 확인한 1차 참고 자료

아래는 브랜드 자산을 복사하기 위한 레퍼런스가 아니라 서비스마다 독립적인 물성과 경험 언어를 만드는 출발점이다. 로고·제품 사진·고유 패키지 도안은 가져오지 않았다.

1. [Aesop — Philosophy on design](https://www.aesop.com/philosophy-on-design.html): 장소의 맥락과 기능에 맞는 디자인 언어를 택한다는 공식 설명을 확인했다. 피부는 밝고 정돈된 상담실, 컬러는 편집물, 와인은 감상 공간으로 서로 다른 구조를 정하는 원칙에 반영했다. 페이지에는 각 공간 사진과 디자인 접근 설명이 함께 제시된다.
2. [Aesop — Philosophy on product](https://www.aesop.com/philosphy-on-products.html): 제품 사용성과 고객의 실제 필요를 출발점으로 삼는다는 설명을 참고했다. 피부 프로그램은 장식적인 분석 기계보다 읽기 쉬운 일상 루틴 노트라는 방향을 택했다.
3. [Blue Bottle Coffee — The Blue Bottle Color Palette](https://blog.bluebottlecoffee.com/posts/the-blue-bottle-color-palette): 공식 디자인 글에서 푸른 포인트, 안개빛 회색, 밝은 목재를 통해 커피와 대화에 시선을 모으는 접근을 확인했다. 커피 프로그램은 자체 오트·블루 팔레트와 넉넉한 종이 여백으로 해석했으며 브랜드 고유 색상이나 마크를 복제하지 않았다. 첫 페이지 열기는 실패했지만 공식 검색 결과의 본문을 통해 읽었다.
4. [Diptyque — The Story of Diptyque](https://us.diptyqueparis.com/en-us/pages/the-story-of-diptyque): 예술가의 작업실, 호기심의 수집, 자연·여행·그래픽 아트에서 오는 향의 이야기를 확인했다. 향수 프로그램의 독립적인 식물 도감과 시향 기록이라는 컨셉에 반영했다. 브랜드 타원 라벨이나 서체를 재현하지 않는다.
5. [Glossier — Makeup](https://www.glossier.com/pages/makeup): 공식 메이크업 페이지의 제품별 표현, 룩과 조합 중심 안내를 참고했다. 메이크업은 장비 대시보드보다 백스테이지에서 룩을 고르는 큰 거울과 화장품 견본으로 해석했다.
6. [OPI — Nail Polish, Nail Care & Nail Art](https://www.opi.com/): 공식 페이지의 네일 컬러·아트 탐색을 확인했다. 네일은 손끝을 작은 작품으로 고르는 팝 아트 스티커 숍으로 해석했다.

칵테일의 원형 잔·긴 카운터, 미각의 도장·티켓, 소믈리에의 황동 액자는 서비스 자체의 현장 오브젝트에서 도출한 독자적인 시각적 해석이다. 위 브랜드들이 이 데모를 제작·검수·보증했다고 표시하지 않는다.

## 분담 검증

- 아트디렉션 설정 9개, composition 9종, 밝은 테마 6개를 실행 검사로 확인했다.
- CSS의 119개 서비스 규칙이 모두 서비스 slug에 한정되며 전역 셀렉터와 `font-size` 축소 규칙이 없음을 확인했다.
- 종이 배경 대비 본문 잉크 대비는 모두 10:1 이상, 보조 본문도 4.5:1 이상, 주요 버튼도 5.8:1 이상이다. 브라우저에서 선택한 카드의 설명문 대비가 낮았던 향수·커피·미각의 3개 색을 보정해 각각 5.10:1, 5.29:1, 5.59:1로 재확인했다. 9개 서비스의 첫 옵션 선택 상태에서 최소 설명문 대비는 4.60:1이다.
- Playwright에서 9개 서비스 × 1440px/320px, 총 18개 시작 화면의 실제 제목·본문 서체 로딩, 모달과 문서 가로 넘침 0, 제목·옵션 텍스트 잘림 0, 선택 후 다음 단계 진입을 확인했다. 제목은 데스크톱 약 52px/모바일 38px, 시작 화면 본문은 18px이다. 결과: `.playwright-mcp/demo-art-direction/beauty-intro-report.json`.
- 피부·커피는 1440px/320px에서 각각 샘플 입력부터 결과까지 진행했다. 총 4개 결과에서 가로 넘침 0, DOM 텍스트 잘림 0, 최소 DOM 본문 15px, 브라우저 오류 0을 확인했다. 외부 AI 호출은 로컬 503 응답으로 대체해 샘플 결과 경로를 검사했다. 결과: `.playwright-mcp/demo-art-direction/beauty-result-report.json`. 발견한 반투명 패널·하늘색 라벨 대비 문제는 공통 테마의 불투명 종이색과 프로그램 강조색으로 보정했다.
- 사진 프레임·배경·스와치·모바일 버튼·결과 루틴을 저장한 스크린샷으로 육안 확인했다. 인쇄 영수증의 캔버스 글자는 DOM 텍스트 최소 크기 검사의 대상이 아니다.
