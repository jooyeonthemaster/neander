# 견적 미리보기 옵션 단계 통합 조사

후속 반영: 키오스크 결과 인쇄 옵션·단계를 제거하고 기존 초안에서도 인쇄 비용을 제외한다. 브랜드 적용·콘텐츠 커스텀·전용 체험 개발은 2단계(첫 기기 체험)의 ‘브랜드·맞춤’ 탭으로 옮겼다. 1대는 2단계, 4대는 기기별 선택을 포함해 5단계다. 공간 디자인의 포토존·추가 조명은 ‘포토존·조명’으로 합쳤다. 팝업 공간은 기존 평당 120만원, 최소 10평 기준 예상 제작비를 합계에 포함한다. 아래 조사 당시의 프린터·별도 브랜드 단계·맞춤 공간 합계 제외 지침은 더 이상 현재 동작이 아니다.


조사일: 2026-09-28. 대상: `/quote-preview`의 6개 체험 옵션과 바깥 견적 흐름.

이번 작업은 조사이며 앱의 옵션 구성은 변경하지 않았다. 포토부스의 인화·부스 외관 통합까지 반영된 상태를 기준으로 한다.

후속 변경: 같은 날 사용자 요청으로 실험 페이지의 키오스크 월 구독과 개월 수 선택을 제거했다. 아래 표와 실측은 제거 전 조사 기록이며, **‘기본 구성+상시 기간’ 병합안은 더 이상 적용 대상이 아니다.** 현재 키오스크는 행사 대여만 제공하며 `대수 → 기기별 체험 → 결과 출력 → 브랜드 적용`의 4~7단계다. 이전 월 구독 선택도 행사 대여로 정규화한다.

추가 반영: 향수의 향·포장을 한 단계로 합치고, 조향팀 수를 기본 구성의 체험 인원 바로 아래로 옮겨 이후 분석 방법과 기기 대수도 한 단계로 합쳐 현재 향수 옵션은 4~5단계다. 현장 터치스크린을 고르면 같은 단계 바로 아래에서 1~4대를 선택한다. 향 구성은 기본30가지 향/행사 전용 향 개발(89만원, 부가세 별도) 선택으로 바꿨다. 포장 선택을 작은 3열 카드로 배치하고 단박스 인원 증액 안내가 보일 때 중복 설명을 줄였다. 아래 DOM 단순 조합 실측은 이 배치 변경 전 기록이다.

## 결론과 우선순위

**우선 합칠 곳은 세 군데다.** 향수의 분석 방법·대수, 공간 디자인의 포토존·조명, 커스텀 콘텐츠의 기획 상담·운영 관리는 현재 설명을 유지한 단순 조합에서도 PC와 모바일에 여유 있게 들어왔다.

| 우선순위 | 권장 변경 | 단계 수 변화 | 조건 |
|---|---|---|---|
| 1 | 향수 분석 방법 + 분석 기기 수 | 6~8 → 6~7 | 기기를 고른 경우에만 같은 화면에 대수 표시 |
| 1 | 공간 포토존 + 추가 조명 | 3~4 → 2~3 | 토글 두 개를 한 ‘공간 연출’ 단계에 배치 |
| 1 | 커스텀 AI 기획 상담 + 운영 관리 | 3 → 2 | 일회성 기획비와 월 관리비 구분 |
| 2 | 미디어 제작 규모 + 센서 | 2 → 1 목표 | 영문 모바일에서 9px 초과하므로 간격·배치 조정 필요 |
| 2 | 키오스크 기본 구성 + 상시 기간 | 4~8 → 4~7 목표 | 모바일에서 대수·개월 입력 배치 및 말풍선 위치 개선 필요 |
| 2 | 향수 브랜드 향 + 포장 | 위 1순위 반영 후 6~7 → 5~6 목표 | 인원 증액 안내를 유지한 채 모바일·영문 배치 재설계 |
| 2 | 공간 크기 + 포토존·조명, 맞춤 면적은 별도 | 위 1순위 반영 후 2~3 → 1~2 목표 | 간격을 줄여도 영문 모바일 17px 초과. 문구·배치 개선 필요 |
| 3 | 키오스크 출력 + 브랜드 적용 | 위 기본·기간 통합 후 4~7 → 3~6 목표 | 현재 내용 그대로는 높이 초과. 중복 설명과 선택 카드 배치 재설계 |
| 3 | 키오스크 체험 배정을 한 단계로 | 위 변경까지 포함하면 3단계 목표 | 기기 번호별 확인 상태와 다음 기기 안내 추가 필요 |

포토부스는 현재 4단계를 유지하는 것이 좋다. 대수와 인화·외관을 더 합치면 데스크톱에서도 높이를 크게 초과한다. 사진 스타일은 카드를 좌우로 탐색하는 현재의 독립 단계를 유지한다.

향수는 순서 조정도 함께 검토할 만하다. 인원·용량 다음에 브랜드 향·포장을 두고, 분석 기기와 조향팀을 뒤에서 결정하면 단박스 선택으로 300명으로 바뀐 인원을 보고 팀 수를 고를 수 있다. 현재는 조향팀을 고른 뒤 포장에서 인원이 바뀔 수 있다. 팀 수를 자동으로 늘리는 변경은 포함하지 않는다.

## 현재 흐름 전수 목록

괄호 안은 선택에 따라 생기는 단계다. N은 키오스크 대수이며 1~4대다.

| 체험 | 현재 순서 | 단계 수 |
|---|---|---|
| AI 향수 체험 | 부스 공간 → (맞춤 공간 넓이) → 인원·향수 용량 → 분석 방법 → (분석 기기 수) → 조향팀 → 브랜드 향 → 선물 포장 | 6~8 |
| AI 포토부스 | 대수 → 사진 스타일 → 인화·부스 외관 → 촬영 화면 | 4 |
| AI 키오스크 | 이용 방식·대수 → (상시 이용 개월) → 1~N번 기기의 체험 → 결과 출력 → 브랜드 적용 | 행사 N+3 / 상시 N+4, 전체 4~8 |
| 공간 디자인 | 크기 → (맞춤 공간 넓이) → 포토존 → 추가 조명 | 3~4 |
| 인터랙티브 미디어 아트 | 제작 규모 → 추가 센서 | 2 |
| 커스텀 AI 콘텐츠 | 제작 범위 → 기획 상담 → 운영 관리 | 3 |

현재 과도하게 나뉜 이유는 입력 그룹의 `OptionTopic`을 각각 독립 페이지로 만드는 구조 때문이다. 체크박스 하나인 브랜드 향·포토존·조명·기획 상담도 한 페이지씩 차지한다. 단계 수보다 **하나의 결정을 완성하는 데 필요한 입력을 함께 보여주는지**를 통합 기준으로 삼는 편이 적절하다.

## 통합할 때 유지할 동작

- 바깥의 **시작 방법 → 행사 정보 → 체험 선택 → 견적서 받기** 순서는 유지한다.
- 하단 이전·다음·완료를 중심으로 순서대로 확인하도록 한다. 선택하지 않았다는 이유만으로 다음 진행을 막지 않는다.
- 조건부 입력은 해당 선택 바로 아래에 나타나게 한다. 입력을 숨겨도 기존 데이터의 저장·복원 규칙을 임의로 바꾸지 않는다.
- 향수 조향팀은 기본 1팀, 최대 총 3팀이다. 분석 기기 수와는 별개다.
- 향수 단박스의 최소 300명 변경과 다른 포장으로 돌아갈 때의 인원 복원을 유지한다. 가격이 바뀌는 이유는 같은 화면에 보이게 한다.
- 맞춤 면적의 평/㎡ 선택·환산·저장 정밀도와 상담 후 산정 안내를 유지한다.
- 키오스크는 기기당 체험 1종이다. 동일 체험 중복 배정과 ‘상담 후 결정’을 허용한다. 프린터 옵션은 현재처럼 선택한 전체 기기에 적용한다.
- 키오스크 프린터는 대당 비용, 브랜드·콘텐츠 변경은 1회 비용이다. 한 화면에 묶더라도 같은 과금 방식처럼 보이지 않게 한다.
- 여러 기기의 체험을 하나의 단계에 묶는 경우 **체험 선택 수와 기기 확인 수를 구분**한다. 미정으로 검토를 마친 기기도 있으므로 선택된 체험 개수만으로 완료 여부를 판단하지 않는다.
- 여러 옵션을 합쳐도 견적 항목과 요금은 각각 유지한다. UI 통합은 패키지 가격 신설을 의미하지 않는다.

공간 크기·포토존·조명 조합도 추가 측정했다. 24px 간격에서는 노트북 약 303px, 모바일 한국어 350px·영어 382px였다. 간격을 16px로 줄이면 노트북 약 287px, 모바일 한국어 334px·영어 366px로, 영문 모바일은 여전히 17px 초과했다. 이 대안도 그대로 합치기보다 문구와 배치를 조정한 뒤 적용하는 대상으로 분류한다. ## 바깥 흐름과 중복 입력

행사 정보는 현재 유형·전체 방문 인원·기간·지역 4개 입력과 날짜·운영 시간·현장 지원 인력·전날 설치 4개 입력의 두 페이지다. 두 페이지를 그대로 합치면 모바일에서 8개 입력이 이어진다. 현재의 스크롤 최소화 목적에는 두 페이지 유지가 맞다. 행사 전체 방문 인원과 향수를 가져갈 인원, 현장 지원 인력과 조향팀은 서로 다른 의미이므로 하나의 값으로 합치지 않는다.

향수의 부스 공간과 공간 디자인의 크기·넓이는 같은 `spatialDesign` 값을 편집한다. 향수에서 고른 공간을 공간 디자인에서 다시 처음부터 묻게 되는 부분은 별도의 개선 후보다. 이미 선택한 크기 요약과 ‘수정’ 버튼을 보여주고 공간 연출로 안내할 수 있지만, 실제 저장 상태와 서비스별 확인 진행을 함께 설계해야 한다.
