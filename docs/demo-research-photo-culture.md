# 패션·포토·엔터테인먼트·문화·여행·웨딩 데모 개편

작성일: 2026-09-23. 대상 17개 서비스. 기존 촬영·선택·프린트 흐름에 서비스별 사전 브리핑 2문항씩 총 34문항을 추가했다. 추가 답변은 `answers.experienceProfile`로 보관하고 각 모듈의 AI 요청에 전달한다. 공통 체험 프레임이 검증된 선택지를 해석해 결과 노트와 출력물에 담고, 서버의 공통 생성 컨텍스트가 텍스트·이미지 프롬프트에 반영한다.

## 연구에서 채택한 내용

- NIDCD의 목소리 관리 안내는 피곤하거나 쉰 목소리를 쉬게 하고, 과도한 고음·큰 소리를 강요하지 않으며, 소음이 있는 환경에서 무리하지 않도록 안내한다. 따라서 녹음 환경·연습 목표를 먼저 받고 편한 높이와 짧은 휴식을 권하는 코칭으로 설계했다. 10초가 임상 진단에 충분하다는 의미는 아니다. 녹음 길이 증가는 체험 문장과 재청취의 여유를 위한 구현 결정이다. [원문](https://www.nidcd.nih.gov/health/taking-care-your-voice)
- UNESCO는 불국사의 건축·보존 상태를 설명하고, 수원화성의 복원은 역사 기록에 근거한 실제 보존 활동으로 설명한다. 생성 AI의 이미지는 그러한 검증된 복원과 구분해야 하므로 '상상 장면', '빛바랜/컬러 연출'로 표시했다. 수원화성의 복원·재건 시작 연도는 UNESCO가 안내하는 1964년을 반영했다. [불국사](https://whc.unesco.org/en/list/736) · [수원화성](https://whc.unesco.org/en/list/817/)
- 한국관광공사의 열린관광 서비스는 이용자의 관광 접근성을 별도 정보로 제공한다. 이를 참고해 일반 취향 질문 외에 짧은 보행·계단 없는 동선·휴식 같은 환경 조건을 묻도록 설계했다. 개별 시설의 현재 접근성은 이 데모에서 실시간 검증하지 않는다. [열린관광 모두의 여행](https://access.visitkorea.or.kr/)

나머지 색·질감·조명·구도·기념 목적 문항은 임상적/역사적 정확도를 주장하는 검사가 아니라 참여자가 원하는 결과를 명시하는 제작 브리프다. 외부 자료로 검증된 진단 문항이라고 주장하지 않는다.

## 구현·검증

- 데이터: `src/data/demo-experiences/photo-culture.ts` — 17개 슬러그, 각 2개 준비 안내·2문항·3단계 처리 메시지.
- 모듈: 위 17개 `src/components/demo/demos/*Demo.tsx`의 모든 AI 생성 요청에서 `experienceProfile` 전달.
- 개별 서버 명세: `future-family.ts`, `voice-lab.ts`, `couple-chemistry.ts`의 입력/응답 스키마 호환성을 유지하면서 프롬프트 한계와 창작 목적을 수정.
- 타입 검사: `npx tsc --noEmit --incremental false` 통과.
- 대상 파일 ESLint 통과. 브라우저에서의 전체 서비스·모바일·출력 통합 확인은 공통 체험 프레임 작업과 함께 수행한다.

함수 단위 실행 검증도 수행했다. 실제 TypeScript 함수 본문을 추출해 AI/로컬 결과 각각의 MV 3개 길이 설정(6개 경우), MemoryMovie의 3개 순서 설정과 사용자 엔딩 보존, 17개 디자인/34개 문항의 선택지·ID·준비 안내/처리 단계 구성을 확인했다. 모두 통과했다. 이 검증은 브라우저 장치 권한이나 외부 AI의 실제 응답을 대신하지 않는다.


## 최종 정합성 감사

전체 41개 모듈과 41개 AI 호출을 AST로 확인하여 추가 브리핑의 전달 누락이 없음을 검증했다. 모든 서비스에서 첫 선택·마지막 선택의 서버 프롬프트가 다르고, UI에 표시한 신뢰된 `outcome`이 서버 프롬프트에 동일하게 들어간다. 허용되지 않은 질문/선택지와 임의 지시문은 정규화 단계에서 버려지는 것도 확인했다. 실제 API의 AI 생성 품질을 보증하는 테스트는 아니다.

추가 수정: 아이돌 메이크업 결과의 임의 '카메라 흡입력·무대 장악력' 점수를 제거하고 선택한 강도·포인트의 레시피로 교체했다. 로컬 사진 합성도 강도·눈/립 포인트에 따라 실제 안료 레이어 투명도가 달라진다. 창작 프로필의 날짜는 실제 생일로 오해하지 않도록 '데뷔일 (창작)'로 표시했다. 셀럽 무드의 로컬 예시 유형은 사진 해시 대신 직접 선택한 캐스팅 무드로 정한다. 보이스 로컬 예시에서 짧은 음높이만으로 허스키 성부나 고음 능력을 단정하는 표현을 제거했다.
