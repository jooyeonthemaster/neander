기본 카메라가 이미 포함되어 있으므로 3D 선택 시 카메라 전체 비용을 재청구하지 않고 추가금 50만원을 적용한다. 세트를 추가하면 이미지 카메라 30만원에 3D 차액 50만원을 더한 80만원으로 일관되게 계산한다. 구매가가 아닌 재사용 장비의 행사 대여·연동·보정 비용으로 판단했다. 이는 제한된 공개 자료를 바탕으로 정한 가격이며 실제 원가·현장 수익성까지 확인된 값은 아니다.

센서 옵션은 행사당 1회 계산하고 운영일이 늘어날 때는 기존 일별 운영료를 적용한다. 기존 저장본에서 센서 종류가 없으면 기본 이미지 카메라로 읽는다. 종전 일률적 추가 센서 100만원은 위 종류별 단가로 바뀐다. 공유 계산 엔진이므로 화면·가견적서와 기존 견적 페이지의 재계산에도 같은 단가가 반영된다.

## 커스텀 AI 콘텐츠

사용자 지정 금액: 기획부터 함께하기 300만원, PG 연결 100만원(각 1회·부가세 별도). PG는 1개 결제사 연동 개발 옵션이며 가입비·거래 수수료는 별도다. 실제 PG 계약이나 결제 기능을 이 견적 페이지에서 실행하지 않는다.

태블릿은 특정 행사 맞춤 콘텐츠를 설명하는 UI 예시이며 기기 대여를 포함하지 않는다. 선택한 행사 유형, 단일/복합 제작, 기획, 결제 연결, 운영 관리가 화면에 반영된다. 클릭하면 참여/결과 예시를 전환하며 실제 AI 생성 요청이나 결제는 하지 않는다.
